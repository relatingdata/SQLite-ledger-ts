# Classification Neutrality: Impact Analysis

Generated by `scripts/analyze-classification-neutrality.ts` (`make analyze-classification`) — never hand-edited.

**The principle measured:** hot/cold, storage, division and category are merely *suggested* classification hierarchies a business may choose — a wine shop might use hot/cold, a hardware store inside/outside. Locations and Items are the real things. A classification word in a function name, table name, route, or hardcoded string is a place where one business's assumption is baked into code.

A hit is one of three kinds: an **identifier** (in code — a name), a **string** (a hardcoded value), or a **comment**. Identifiers and strings are the ones that can change behaviour; comments only describe it.
