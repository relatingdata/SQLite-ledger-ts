\section*{Purpose}
\addcontentsline{toc}{section}{Purpose}

This is not the Programmer's Manual. The Programmer's Manual (a
separate, deliberately short document) describes only the system as
it stands today, with the minimum background needed to reimplement
it. This document is its full, un-trimmed source material: every
design investigation, planning document, rejected approach, and
"here is the real mistake that was made and how it was found" account
this project's own history produced, kept here in full rather than
discarded, so the reasoning behind a current decision can still be
traced back to the real, specific incident that produced it. A
section appearing here is not a current instruction to follow --- it
is a record of how the current, real system in the Programmer's
Manual came to be the way it is. Where the two disagree, the
Programmer's Manual is correct about the system as it stands today;
this document is correct about how it got there.
